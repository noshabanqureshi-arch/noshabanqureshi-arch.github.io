# Square Social Studio — Activation Execution Notes

This working file tracks what can be activated immediately in the static website and what still depends on an external account, credential, protected delivery system, finished media, or genuine customer evidence.

## Can be completed in the repository now
- Free-resource access path that does not falsely imply email automation is active.
- Low-touch premium-service application/pre-qualification page without exposing a personal email address.
- Clear live/planned status on courses and Vault.
- SEO/accessibility/navigation/sitemap updates for all new pages.

## External activation gates
- Branded sender/support email and custom domain configuration.
- Email-marketing platform, consent records and unsubscribe processing.
- Analytics property / measurement ID and privacy implementation.
- Finished mini-course media and protected course-access delivery.
- Vault platform/content delivery before collecting subscription payments.
- Genuine customer reviews/case examples before publishing social proof.

These gates must not be faked or bypassed merely to make the site appear more complete.
