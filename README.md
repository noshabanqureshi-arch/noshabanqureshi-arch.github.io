# Square Social Studio Shop

A multi-page eCommerce website for Square Social Studio, an Edmonton-based digital content brand serving Canadian small businesses.

The website includes:

- Home, About, Contact, and Catalog pages
- Six detailed digital products
- Launch Kits and Content Systems collections
- Responsive navigation and mobile layouts
- A demonstration cart and contact form
- Square Social Studio brand assets, colours, positioning, and policies

This repository is configured as a static site for GitHub Pages.
