# Square Social Studio — SEO Content Cluster Plan

Purpose: make the free Resources library work as one connected authority system rather than a set of isolated articles.

This plan does not assume rankings or traffic. Search performance should be evaluated through Search Console after the site is verified and indexed.

## Core audience search problem
Small-business owners are looking for practical answers to questions such as:
- what should I post on social media?
- how do I plan content?
- what are content pillars?
- how often should a small business post?
- how do I use AI for content without sounding generic?
- what social media metrics matter?
- how do I make Reels without becoming a full-time creator?

Square Social's differentiation:
- start from real business knowledge/customer questions,
- use content for a specific job,
- reuse before create,
- choose a sustainable rhythm,
- connect content to business outcomes,
- use AI as production support rather than invented expertise.

# Internal-link rules
1. Every resource should link to 2–4 genuinely related resources.
2. Use descriptive anchor text; avoid repeated generic “click here.”
3. Link to the $27 Starter only when the reader's next problem is planning/implementation.
4. Planned products can be linked as previews only when they are directly relevant; do not imply checkout exists.
5. Keep one primary CTA near the end of each article.
6. Resources should link back to the Resources hub or Start Here where useful.
7. When a new article overlaps heavily with an existing one, update/expand the existing page instead of creating keyword cannibalization.

---

# Content expansion filter
Before creating another SEO page ask:
1. Is there evidence that small-business owners ask this question?
2. Does one of the existing 10 pages already answer it?
3. Can the existing page be improved instead?
4. Does the new page fit a current cluster?
5. What internal pages will link to it and from it?
6. What is the reader's next useful step?
7. Can the article be created from existing Square Social teaching rather than requiring net-new expertise?

If the page has no cluster or next step, do not create it yet.

---

# Search Console review after activation
Once Search Console is connected, review monthly:
- indexed pages,
- queries by resource,
- impressions,
- clicks,
- CTR,
- average position as a directional metric,
- pages with impressions but weak CTR (title/meta test opportunity),
- queries with impressions but incomplete coverage (content-update opportunity),
- pages with no meaningful impressions after enough time (reassess search intent/internal links).

Use actual search data to update the cluster instead of producing endless articles from guesses.
