# Square Social Studio — Customer Canva Template Handoff

## Purpose
Keep the editable business master separate from the version customers receive.

A separate customer-facing copy of the locked-brand **30-Day Content Starter Companion Pack** has been created in Canva and filed in the Products folder. The original business master should not be distributed.

## Required final Canva step
The Canva connector can create/copy designs, but it cannot publish a customer template link permission.

On the **customer-facing copy only**:
1. Open the design in Canva.
2. Select **Share**.
3. Select **Template link** (choose **See all** first if it is not visible).
4. Select **Create template link**.
5. Copy the resulting template URL.
6. Insert that URL into the customer delivery package / delivery platform.

Canva states that a template link lets recipients use the design as a template rather than editing the source design.

## Safety rule
Never use the owner edit URL as the customer delivery URL. Test the final template link from a signed-out/private browser window before public checkout opens.
